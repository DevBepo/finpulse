# FinPulse

Gerenciador de finanças pessoais com integração Open Finance (Banco Inter PF via Meu Pluggy).

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (`DevBepo/finpulse`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`GLOSSARY.md` and `docs/adr/` at the repo root, created lazily via `/domain-modeling`). See `docs/agents/domain.md`.
